# BOCTECHSUP

Hardware maintenance and inventory management site for technical assets such as PCs, laptops, mice, printers, and more.

## Features

- Inventory management for technical assets (create, update, delete, view)
- Built-in RBAC roles:
  - **admin**: full access
  - **technician**: create/update access
  - **viewer**: read-only access
- User action log (login, logout, create/update/delete inventory records)
- Local browser storage persistence for inventory and logs
